# Asset-Bibliothek

- Design-Boards unter `design/reference/` als Stil-/Layoutreferenz; sie dürfen **nicht** als einzelne UI-Komponenten oder scheinbar echte Reisebilder ausgegeben werden.
- SVG-Markenassets unter `assets/brand/` sind neu erstellte technische Platzhalter im vorgegebenen Farbkonzept.
- Für produktive Galerie/Stationen: eigene Reisebilder des Nutzers bzw. generierte/licenzierte Naturbilder mit Verwendungsrechten und Quelldokumentation. Das aktuelle Paket liefert hochwertige Designreferenzen, aber **keinen umfangreichen Einzelbild-Fotobestand**.
